# Himalayan Geological Research (HGR)

This folder is designed to live inside the existing parajulinawaraj.com.np website.

## Upload location

Upload the entire `himalayan-geological-research` folder into your website's public_html/root directory.

Main URL:
https://www.parajulinawaraj.com.np/himalayan-geological-research/index.html

## Structure

- index.html — HGR homepage
- publications.html — publication list
- articles.html — articles
- research.html — research themes
- field-studies.html — field investigations
- maps.html — map gallery
- data.html — data landing page
- about.html — about HGR
- css/hgr.css — all HGR styling
- js/hgr.js — navigation and small interactions
- images/ — common HGR images and logo
- events/ — one folder per major research event
- events/rasuwa-2026/ — first event
  - index.html
  - photos/
  - maps/
  - data/

## Important

The JPEGs included in this starter package are visual placeholders/illustrations.
Replace them with your actual field photographs, satellite-derived figures and GIS maps.

Do not place very large raw satellite datasets or DEMs directly on ordinary web hosting.
For large files, use a research repository/cloud storage and link to them from the Data page.
